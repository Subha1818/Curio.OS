
# 🖥️ DREAM.OS — Feature Plan

### Core concept

> **A whimsical desktop operating system running entirely inside the browser.**

Users can explore the OS anonymously, but **logging in unlocks their own personalized desktop/data**.

# 5. 📷 Camera

Browser camera using:

```text
navigator.mediaDevices.getUserMedia()
```

User can:

**Take Photo → Preview → Save**

Saved under:

```text
📁 Camera
   ├── IMG_001
   ├── IMG_002
   └── IMG_003
```

Store the actual images in **Supabase Storage**, not the database.

Set a reasonable user limit.

# 6. 🖼️ Personal Photos

Users can upload up to:

> **10 photos**

These appear in:

```text

```

**Upload photo → Set as wallpaper**

# 9. 🌐 Browser

Don't try to build a real browser initially.

Make it a **fictional DREAM.OS browser**.

### Phase 1

A browser window containing:

* Address/search bar
* Back/forward
* Reload
* Home
* Tabs

But it opens **internal DREAM.OS websites**.

Example:

```text
dream://home
dream://about
dream://music
dream://terminal
dream://subbu
dream://void
```

Later you can add:

* Fake search engine
* Easter eggs
* Internet API integration
* Actual external browsing if technically appropriate

For now, make it an **in-universe browser**.

# 10. 🌌 VOID.EXE

Keep this mysterious.

Initial screen:

> **THERE IS NOTHING HERE.**

Button:

> `[ DO NOT CLICK ]`

Every interaction gradually changes the experience.

Possible progression:

```text
Click 1
"Why?"

Click 2
"Seriously?"

Click 3
"Stop."

Click 4
"..."

Click 5
"Fine."
```

Then the desktop starts behaving strangely.

Potential effects:

* Windows move
* Text changes
* Desktop glitches
* Cursor changes
* Fake system messages
* Hidden commands become available

Eventually:

> **VOID.EXE has noticed you.**

```text
╭────────────────────────────╮
│ 🔐 CLASSIFIED              │
│                            │
│ This folder belongs to     │
│ Subbu.                     │
│                            │
```

### Compliment scoring

Examples:

> "Subbu is the best developer"

> "I love you Subbu"

> "Marry me Subbu"

> "Subbu is the kindest developer"

> "Subbu is awesome"

```text
Compliment detected!

❤️ 87%
```

Only:

> **100% → UNLOCKED**

The button can open a mailto link / contact method.
